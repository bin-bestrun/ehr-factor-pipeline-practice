# EHR Factor Practice Package

This package contains descriptive encounter-level feature examples generated from `ehr_factor_pipeline.py`.

- `factor_index.json` lists the stable IDs and metadata.
- Each `EH###-...` directory contains `SKILL.md`, `scripts/factor.py`, and `references/formula.md`.
- The functions accept the cleaned encounter table and return values aligned to its rows.

These are educational features, not validated clinical scores or tools for patient care. See the project guide and the UCI dataset citation before sharing derived work.
